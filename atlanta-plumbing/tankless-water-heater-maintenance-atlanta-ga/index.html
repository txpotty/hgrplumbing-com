    Tankless Error Code Diagnosis in Atlanta, GA

    An error code is the heater telling you what it saw. On a Rinnai an LC code means scale, on a Navien E003 means no ignition, and on a Noritz a 90 usually means an air or exhaust problem. First we read the code history. If a part has failed, you hear the repair and the price before we start.

    Recirculation and Combi Unit Service in Atlanta, GA

    Built-in recirculation pumps and buffer tanks get hot water to the tap faster, but they also push more water through the exchanger every day, so those units scale sooner. We flush the recirculation loop along with the exchanger. Then we check whether the system uses a crossover valve or a dedicated return line and set the schedule to match.

    What Tankless Maintenance Saves in Atlanta

    Scale on an exchanger acts like insulation. A heavily scaled unit burns more gas per shower than a clean one, and that adds up each month. We lay out the maintenance price next to the likely repair cost so you can decide.

    Rinnai Air Filter and Flame Rod Care in Atlanta

    Rinnai cabinets are tight. We wash the air intake filter and check the flame rod for carbon. On recirculating models we also check the pump schedule, because a wrong setting burns gas for nothing.

    Step-by-Step Tankless Flushing in Atlanta

    First we shut off the gas and power, then close both isolation valves so the heater is cut off from the house plumbing. The pump pulls solution from a bucket, through the cold port, out the hot port and back again. Once the cycle ends, we rinse with clean water and pull the inlet screen. Then we check for leaks.

    Same-Day Tankless Help in Atlanta, GA

    A blinking error code and a cold shower usually mean the heater protected itself from something. Heavy scale or a blocked exhaust is the usual cause. Emergency calls get common parts and a descaling kit, and most heaters run again before we leave.

    Inlet Screen and Air Filter Cleaning in Atlanta

    Grit gets in. The small screen on the cold inlet catches sand and loose scale after a water main repair. On units with an air intake filter, dust and lint load it up and the burner runs rich or throws a combustion code. We clean both on every visit.

    Noritz builds a solid heater, but solid does not mean maintenance-free. We start a Noritz tune-up at the exhaust, checking for soot and any blocked termination. Next comes the combustion air intake and the fan. Last, we check the temperature setting and run a few fixtures at once, which shows whether the unit holds temperature between back-to-back showers.
