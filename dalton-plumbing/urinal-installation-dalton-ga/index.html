    Flush Valve Urinal Installation in Dalton, GA

    Flush valve urinals are the commercial standard. Tankless flushometers deliver a set volume from a 3/4 inch line and recover instantly for the next user. We set the volume to the bowl. Wrong settings stain bowls.

    Sensor Urinal Installation in Dalton, GA

    Sensor valves stop missed flushes and double flushes. Battery or hardwired valves get a tuned sensing range and an optional sanitary flush for idle periods. Expect years between battery changes. Hardwired units need an electrician first.

    American Standard and Kohler Urinal Installation in Dalton

    American Standard and Kohler make the china we install most. The spec sheet makes matching easy. We order both together.
