    Batch Feed vs Continuous Feed in Augusta

    Continuous feed is the type most kitchens have. Flip the switch and it runs until you flip it off. Batch feed only runs with its stopper turned in place, so nobody can reach into a running unit, which some families with small kids prefer and which needs no wall switch at all. Each type gets wired its own way.

    Dishwasher Connection and Air Gap Setup in Augusta

    Nearly every InSinkErator has a dishwasher inlet with a factory knockout plug inside. The plug gets knocked loose and pulled out of the grind chamber. Both appliances get run together.

    Badger Series Installation in Augusta, GA

    The Badger line runs from the 1/3 HP Badger 1 up to the Badger 5XP. All of them use the same quick-lock mount. That shared mount is why a Badger-to-Badger swap is often a 45-minute job, since the upper ring and flange can stay put if they are not corroded. No cord comes in the box, so the cord kit is on us.

    Badger Disposal Install in Augusta

    Most replacement disposals in local kitchens are a Badger. A 1/3 to 3/4 HP Badger handles normal scraps and fits almost any sink base cabinet. We hang it on the quick-lock mount, connect the discharge tube and add a cord kit if the old unit was plugged in, then run a test grind with cold water running to clear the chamber. About an hour, usually.

    First-Time Disposal Installation in Augusta

    Kitchens that never had a disposal need some rework. The sink needs a disposal flange. The tailpiece and trap have to be reworked, and the cabinet needs a switched outlet, which means an electrician if there is no power under the sink already. Drain slope to the stack gets checked as well.

    Upgrading Your InSinkErator in Augusta, GA

    Moving up from a 1/3 HP builder unit to a 3/4 HP Evolution changes more than the grind. Expect the new unit to sit lower in the cabinet. That extra height can put the discharge outlet below the trap arm, so we measure the drop before install day and lower the trap or the arm if the numbers do not work. The circuit gets checked for the bigger motor's draw too.

    Standard InSinkErator Installation in Augusta

    A standard install goes into a sink that already has a drain and power. We take the old disposal down, scrape the old putty off the flange and set a new flange with fresh putty. Then the mount ring goes on. The unit hangs on the ring, locks with a quarter turn, and the discharge tube meets the trap on a new slip-joint washer. Power comes from a cord kit or the existing hardwire, checked for ground before the breaker goes back on.
